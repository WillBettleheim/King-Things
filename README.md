# ♟️ KING THINGS

### An Immersive 3D Chess Experience

**KING THINGS** is a browser-based chess game that combines strategic gameplay with immersive 3D environments and diverse visual themes. From atmospheric gothic settings and scenic landscapes to vibrant cityscapes and Japanese-inspired surroundings, KING THINGS brings a fresh visual experience to the timeless game of chess.

The project explores the intersection of chess, interactive web development, and environmental design, creating a game where every setting brings its own atmosphere to the board.

---

## ✨ Overview

Chess is a game of strategy, patience, and calculated decisions. KING THINGS builds on that foundation by introducing a variety of immersive environments, allowing players to experience the game in different visual settings.

Rather than limiting chess to a traditional board, the project explores how scenery, atmosphere, and customization can make a browser-based chess experience more engaging.

## 🎮 Features

- **Multiple immersive environments** — choose from a collection of distinct visual themes.
- **Gothic atmosphere** — a darker, atmospheric setting for chess.
- **Nature-inspired landscapes** — environments inspired by forests, mountains, and coastlines.
- **Urban environments** — city-inspired settings, including New York.
- **Japanese-inspired themes** — Sakura and Japan environments offering distinct Japanese visual styles.
- **Weather variations** — weather effects available in the New York environment.
- **Browser-based gameplay** — launch the game in a compatible modern browser.
- **Expandable design** — a foundation for further improvements to graphics, animations, gameplay, and customization.

The available gameplay and visual features are determined by the current implementation.

## 🚀 Getting Started

### Prerequisites

- A modern web browser, such as Chrome, Firefox, Safari, or Edge.
- Git, if you want to clone the repository.

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/WillBettleheim/King-Things.git
```

**2. Enter the project directory**

```bash
cd King-Things
```

**3. Launch the game on macOS**

```bash
open gothic-chess.html
```

Alternatively, open `gothic-chess.html` directly in your browser.

No build step is required if the standalone HTML file contains everything needed to run the application. An internet connection may be necessary if external libraries, fonts, or assets are loaded remotely.

## 🌐 Deployment

KING THINGS can potentially be hosted using GitHub Pages if its dependencies are compatible with static hosting.

### Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under build and deployment, select **Deploy from a branch**.
4. Choose the `main` branch and the root directory.
5. Save your settings and wait for deployment to complete.

Because the main file is named `gothic-chess.html`, the game may be available at a URL ending in `/gothic-chess.html`. An `index.html` entry point can be added if you want the game to open directly from the site's root URL.

After deployment, test the game to ensure that the environments, external assets, and interactive features load correctly.
